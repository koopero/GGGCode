## Responses & failures

Every command returns a control line. By default it is `OK` (an `O`-prefixed okay return); a request id set with `O<id>` is echoed back on that line. A failure is signalled by an `F<code>` argument on the return line, where `<code>` classifies the reason:

| code | name |
| --- | --- |
| `F1` | CommandNotFound |
| `F2` | QueueOverflow |
| `F3` | LoopOverflow |
| `F4` | StackError |
| `F5` | BufferNotFound |
| `F6` | ProcedureNotFound |
| `F7` | BadOperator |
| `F8` | BlitFailed |
